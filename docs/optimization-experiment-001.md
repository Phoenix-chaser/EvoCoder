# EvoCoder：技能适用判断与动作纠错

本轮是人工实现的执行工程优化，不是新的技能自进化实验。固定已有修订技能，没有生成或修改技能、发布版本或重跑旧终评。实验只用两道已见 Click 开发案例，另用已见的 dotenv 空缓存案例核对正向适用。

## 实现

- 路由只读取公开问题、技能适用条件和禁用条件，不读取修复步骤、历史分数或隐藏测试。应用需有合法条件索引、问题原文引用且无阻断条件；skip/uncertain/非法路由均显式跳过技能。这仍是模型判断，原文引用只能证明有出处，不能证明语义判断一定正确。
- 记录 requested_skill_id 与实际 applied_skill_id；跳过技能的失败不能被当作父版本失败来修订。
- 完整且已结算的动作参数校验失败会返回反馈，不执行动作、不裁剪参数；模型可在剩余预算内纠正。网络超时、未知函数和不确定计费仍终止，不自动重发 HTTP。
- 原来的 16 步上限保持不变，路由与被拒绝的动作均占模型步骤；工具次数另外统计。
