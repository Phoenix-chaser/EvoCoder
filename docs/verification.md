## 结论的适用范围

本次证明实现了真实代码执行、失败证据绑定、持久技能修订、拒绝/接纳和后续复用的工程闭环。

这些任务共用合成生成器，Mock 的解题与技能提案规则由开发者编写。2/4 → 4/4 验证了夹具和发布门禁的工程行为，真实修复收益需用独立的真实模型对照评估。

初版当时尚未完成真实模型付费验证。自然 issue 数据集、官方 SWE-bench 适配、无记忆/RAG/冻结技能/持续修订四组实验、多个顺序的统计比较、长期遗忘评测、可执行工具自动生成目前仍未完成。

首次 Docker 调试曾遇到只读根文件系统下 docker cp 写入失败，以及 docker cp 未读取 tmpfs 内容的问题；失败轨迹保留在 `experiments/core-smoke*`。当前使用隔离 Python 进程播种与导出工作区，最终测试已覆盖相应执行路径。
